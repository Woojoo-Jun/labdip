Firebase 연결 설정

1
Firebase 프로젝트 만들기
console.firebase.google.com → 프로젝트 추가 → 생성
2
Firestore Database 활성화
데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기 → 테스트 모드 → asia-northeast3
3
웹 앱 등록 후 아래 값 입력
프로젝트 설정(⚙️) → 앱 추가 → 웹 → firebaseConfig 값 복사
